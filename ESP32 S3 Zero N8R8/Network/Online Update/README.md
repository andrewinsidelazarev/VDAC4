# VDAC4 Online Update 2

`VDAC4UPD.WMF` — плагин Wild Commander: обновляет с GitHub всю плату VDAC4, без ПК и без USB.
В списке — каждая часть платы, рядом то, что стоит сейчас, и то, что опубликовано:

| Строка | Что это | Текущее / доступное |
|---|---|---|
| `ESP32-S3 firmware` | прошивка ESP (раздел OTA) | версии `0.1.123` / `0.1.124` |
| `BL616 firmware` | прошивка BL616 модуля Tang | номера `41` / `42` |
| `FPGA slot 0 TS-Config`, `slot 1 FT812`, `slot 3 video` | ядра во flash Tang | версии из README прошивки Tang |
| `Tang SD: CORES/…` | ядра и их слои ESP на microSD Tang | размеры |
| `WC/…`, `WC/ESP/…` | плагины VDAC4 и модули ESP на карте Evo | размеры |

Качает, проверяет и ставит всё сама ESP; через Z80 идут команды, список и индикатор, а файлы карты
Evo — через мост VFS (как у [WC Update](../WC%20Update/README.md)). Устройство, протокол и правила
отбора файлов — [DESIGN.md](DESIGN.md).

Источник — этот репозиторий, ветка `main`. Эталон — git-SHA файлов одного коммита (два запроса к
API GitHub, без входа их 60 в час): отличие в любом байте видно, даже если номер версии не менялся.

Не трогаются никогда: дискета Amiga и прочие данные пользователя на карте Tang (только `CORES/`),
слот 2 flash Tang (шрифты FT812), настройки Tang, чужие файлы в `/WC`.

## Установка

1. `build/vdac4/VDAC4UPD.WMF` — в `/WC/` (замена прежнего `VDAC4 Online Update` 1.0), имя — строкой в
   секцию `[PLUGINS]` файла `/WC/wc.ini`.
2. В `/zifi/zifi.ini` — действующие `ssid:` и `password:`.
3. Нужна прошивка ESP **0.1.124** или новее. Со старой плагин пишет
   `ERROR: ESP firmware has no board update (needs 0.1.124+)` — её один раз ставят прежним путём
   (прошивальщик или `esp_tool.py --net`).

## Работа

Запуск — из меню плагинов (F10): `VDAC4 Online Update`.

1. Плагин перезапускает ESP (`SYS_RESET`: освобождается память для HTTPS), ждёт `READY`, передаёт
   `zifi.ini` и просит сверку (`VUP_START`).
2. ESP берёт с GitHub дерево репозитория, затем читает плату: SHA-256 своего раздела, номер BL616,
   слоты flash Tang (по 1 МБ, со сверкой git-SHA), файлы карты Tang и карты Evo. Строки появляются
   по мере сверки. Состояния: `same`, `DIFFERS`, `NEW`, `OLDER` (опубликованная старше — понижение
   запрещено, строку не отметить), `READ ERR` (не прочиталось: нет связи с Tang, Tang работает не в
   TS-Config, карта Tang отдана WC и т. п.).
3. Отличающиеся и новые строки отмечены сами. `Space` — отметка строки, `A` — все, `Enter` —
   поставить отмеченное, `Esc` — выход без изменений.
4. Ставится в безопасном порядке: карта Evo, карта Tang, BL616, слоты 1, 3, затем 0, **ESP последней**.
   Каждая часть — со сверкой: скачанный файл — по git-SHA, слот — чтением flash обратно, файл карты —
   через временный файл и чтение обратно. Не сошлось — строка `FAILED`, прежнее цело, остальные строки
   продолжаются. Новый слот 0 (TS-Config) загрузится при следующем включении.
5. Поставив свою прошивку, ESP показывает `ESP firmware installed - waiting for the ESP restart` и
   перезапускается; плагин ждёт `READY` и проверяет всё заново уже новой прошивкой.

После Enter питание не выключать.

## Сборка и проверка

```powershell
& ".\Online Update\build.bat"
```

Сборка — только для платы VDAC4 (`-DZIFI_SPI`, канал SPI без DMA). Основа — плагин WC Update (окно
списка, мост VFS, повтор потерянных событий); прежний плагин 1.0 (только ESP) заменён.

- Плагин в эмуляторе Z80 со стендом канала SPI: `Network/tests/test_online_update_z80.py`.
- Обновлятор ESP на ПК (настоящий код прошивки, «GitHub» из папки, модель платы и эмулятор WC):
  `Firmware/tests/test_vdac4_update_host.py`, стенд — `Firmware/tools/host_vup`.
