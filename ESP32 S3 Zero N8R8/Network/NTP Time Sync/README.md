# VDAC4 NTP Time Sync

Плагин Wild Commander Improved типа `#06` (исполняемый при запуске WC) : после инициализации WC
перезапускает ESP (`SYS_RESET`, как FTP и SMB: запуск WC тождественен сбросу Evo, а RESET
ZX саму ESP не трогает), дожидается её готовности (`PING` до `READY`), загружает
`/zifi/zifi.ini`, передаёт его ESP платы VDAC4 (по SPI) командой `WIFI_INI`, запрашивает
`NET_NTP` и при расхождении не менее минуты обновляет RTC Mr.Gluk.

Формат ответа прошивки: ровно 14 ASCII-цифр `YYYYMMDDhhmmss`, уже с
часовым поясом `time:` из `zifi.ini` (смещение +- относительно UTC (GMT)). При удаче
по тому же ответу NTP ESP выставляет и свои часы. При любой ошибке плагин молча
возвращает управление Wild Commander и часы Evo не меняет.

Если ESP на связи, а время по NTP получить не вышло (нет `zifi.ini`, нет сети, NTP
не ответил), плагин (сборка от 11 октября 2026 года) перед выходом выставляет часы ESP по RTC Evo: команда
`SYS_CLOCK` (прошивка `vdac4-0.1.43`), местное время, пояс — из `time:`. Прошивка
принимает его, только если дата позже 1 октября 2026 года: сбившиеся часы Evo
показывают давнюю дату. По часам ESP ставится время файлов на флешке в разъёме
USB модуля.

## Сборка

```powershell
& ".\NTP Time Sync\build.bat"
```

Результат: `build/vdac4/VDAC4NTP.WMF` (только для платы VDAC4; так же его
собирает `build_vdac4.bat`). Сборка использует только файлы текущего проекта:
`src` и `../shared/z80`.

## Установка

Скопируйте `VDAC4NTP.WMF` в каталог плагинов Wild Commander Improved и назовите
его в секции `[PLUGINS]` файла `/WC/wc.ini`. Плагин
типа `#06` выполняется один раз после полной инициализации WC.
