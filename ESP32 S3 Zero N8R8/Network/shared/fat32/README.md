# Драйвер FAT32 для Z80 (копия)

Копия самостоятельного драйвера FAT32 для ZX Evolution — без изменений. Им пользуется
запускатель [`ESP App SPG`](../../ESP%20App%20SPG/README.md), когда приложению нужны файлы
данных с SD-карты Evo (сборка `build.bat ИМЯ.ELF … ДАННЫЕ`).

Откуда: <https://github.com/andrewinsidelazarev/FAT32-Driver-ZX-Evolution>, коммит
`e72839070fcdc8eb0b6dbae2b9f6ff52b0a2a22d` (7 октября 2026). Файлы взяты 23.11.2026 из копии в
проекте DOOM VDAC4 (`third_party/fat32`) и совпадают с ней байт в байт. Автор — Andrew Lazarev,
лицензия MIT ([`LICENSE`](LICENSE)). Документация, проверки и инструменты исходного репозитория
сюда не скопированы: здесь только то, из чего собирается драйвер.

| Что | Где |
|---|---|
| исходник драйвера | `src/` (вход — `src/main.asm`) |
| адреса входов для программ | `include/fat32.inc` (`include/filex.inc` — блок FILEX) |
| обмен с картой через Z-Controller (порты `#57`/`#77`) | `ports/sdzc.asm` |
| сборка | `build.py` → `build/fat32.bin`, `build/fat32-work.bin` |

Сборка: `set SJASMPLUS=E:\zx\z80\zuma\sjasmplus.exe`, затем `py -3 build.py` (так делает
`ESP App SPG\build.bat`, когда есть файлы данных). Папка `build/` в репозиторий не выкладывается.

Как программа ставит драйвер в память (так делает DOOM VDAC4, так делает и запускатель):

- окно `#0000` — ОЗУ (порт `#21AF` = `#0E`), в нём страница с `fat32-work.bin`: буферы и
  переменные драйвера, с `#3900` — таблица процедур порта SD (`#3902` — чтение сектора:
  `BC` — буфер, `DE:HL` — номер сектора);
- окно `#4000` — страница с `fat32.bin`: таблица входов `JP` с `#4000` (`fat32.inc`).

Прерывания на это время должны быть закрыты: в окне `#0000` нет ПЗУ с обработчиком.
