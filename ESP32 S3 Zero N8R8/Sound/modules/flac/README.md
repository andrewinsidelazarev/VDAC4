# FLAC.ELF 1.0

Потоковый декодер native FLAC для ESP32-S3 VDAC4. Файл читается с карты
через плагин Wild Commander; целиком в PSRAM не загружается.

Установка:

- `modules/out/FLAC.ELF` → `/WC/ESP/FLAC.ELF`.
- `modules/out/PLAYER.ELF` версии 1.13 или новее → `/WC/ESP/PLAYER.ELF`.
- `MP3 Player/build/VDAC4MP3.WMF` версии 1.10 или новее → каталог плагинов WC.

Для быстрого обмена блоками 8 КиБ нужна прошивка ESP VDAC4 0.1.42.
На прежней прошивке с поддержкой ELF плагин использует старый протокол.
Плагин распознаёт `.flac` по расширению `FLA` в коротком имени FAT 8.3.
Если WC создал короткое имя без расширения (ошибка обработки четырёх букв),
плагин 1.9 проверяет полное имя через отдельную запись пустого расширения
в заголовке WMF. Принимает только точный суффикс `.flac` без учёта регистра;
остальные имена возвращает WC с кодом 1 до открытия окна и обращения к ESP.
Изменять WC и переименовывать музыку не требуется. Запуск по расширению
сохраняет штатный переход на следующий файл после окончания песни.
Показываются формат `FLAC`, спектр, длительность и обычные органы управления.

В PLAYER 1.13 очередь сжатого FLAC — 256 КиБ PSRAM. Начальной
пребуферизации нет: декодирование начинается с первых поступивших данных.
Пустое входное кольцо не вызывает повторное накопление, пока в очереди
готового PCM остаётся хотя бы 100 мс звука. При нехватке PCM повторное
накопление — 96 КиБ. При нехватке памяти очередь — 128 КиБ, повторное
накопление — 48 КиБ, начального порога также нет. Конец входного файла
снимает ожидание порога: короткие файлы тоже играют.
При остановке потока или открытии другого файла большая очередь освобождается.

Плагин 1.10 устанавливает Z80 на 14 МГц через WC API 14 (B=0, C=2).
При завершении, Escape, смене трека и ошибке API 14 (B=#FF) восстанавливает
исходный режим WC. Сам WC не изменяется. Чтение Z-Controller идёт через
WC LOAD512 с DMA, до 16 секторов (8 КиБ) за вызов. Прошивка 0.1.42 принимает
такую порцию одной операцией SPI DMA без XOR/CRC по данным. Этот же канал
используют остальные форматы аудио, SF2, ROM OPL4 и наборы MWK.

Поддерживаются 4–24 бит, моно и стерео; 3–8 каналов сводятся в стерео.
Длительность берётся из STREAMINFO. Перемотка, как у MP3, оценивает позицию
по среднему битрейту, после чего декодер ищет следующий кадр с верной CRC.
Для FLAC с переменным битрейтом переход на 10 секунд приблизительный.

Метки Vorbis Comment: TITLE, ARTIST (ALBUMARTIST как запасной вариант),
ALBUM, DATE/YEAR, TRACKNUMBER. UTF-8 переводится плеером в CP866 для WC.
Номер трека передаётся необязательным callback `zm_source_t::tag` ABI 1.8:
размер `zm_info_t` не изменён, прежние декодеры можно оставить.

Обложка: блок PICTURE с JPEG, приоритет у front cover (тип 3).
Миниатюру создаёт существующий обработчик PLAYER, как для MP3.
Он поддерживает baseline JPEG до 1 МиБ; PNG и ссылки на картинки не загружаются.
Если декодер не передал обложку, после разбора метаданных плагин ищет
`cover.jpg`, `folder.jpg`, `front.jpg` в текущем каталоге, включая существующие
варианты регистра имён. Звук и картинка читаются отдельными потоками WC.

Декодирование: libfoxenflac, закреплённая версия и лицензия находятся в
`components/foxen_flac`. CRC включены. Память декодера выделяется по максимальному
размеру блока и числу каналов STREAMINFO (примерно 40 КиБ для CD-стерео),
плюс буферы ввода/вывода. Большие комментарии и padding обрабатываются по частям.

Сборка: `tools/build_modules.ps1 flac player`, затем `MP3 Player/build.bat`.
Проверки: `tests/test_flac_host.py`, проверки доставки FLAC и обложек в
`tests/test_mp3_plugin_z80.py`; совместимость ELF проверяет
`tools/check_module_symbols.py` при сборке.
