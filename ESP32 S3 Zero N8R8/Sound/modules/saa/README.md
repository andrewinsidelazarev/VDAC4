# SAA.ELF 1.0

Декодер E-Tracker для SAA1099 (SAM Coupe). Принимает `.SAA` и `.COP` с
подписью `ETracker` в смещении 10. Это именно формат присланных примеров;
самостоятельные Z80-проигрыватели и другие форматы Sound Tracker сюда не входят.

Шесть стереоканалов, инструменты, орнаменты, транспозиция, ослабление громкости,
перестановка левого/правого каналов, шум и аппаратные огибающие. Такт трекера —
50 Гц, SAA1099 — 8 МГц, PCM — 44,1 кГц, стерео, с двукратным оверсэмплингом.
Программа доходит до конца списка позиций один раз и сообщает конец песни,
чтобы плагин перешёл к следующему файлу. Петли инструментов и орнаментов
сохраняются. Время и шесть индикаторов выдаются через обычный ABI плеера.

Для установки нужны три файла:

- `modules/out/SAA.ELF` → `/WC/ESP/SAA.ELF`;
- `modules/out/PLAYER.ELF` (1.14) → `/WC/ESP/PLAYER.ELF`;
- `MP3 Player/build/VDAC4MP3.WMF` (1.11) → каталог плагинов WC.

Прошивка 0.1.42 подходит. Плагин использует общий быстрый DMA-обмен, ставит
Z80 в 14 МГц и восстанавливает прежнюю частоту при выходе. Wild Commander
изменять не требуется. После замены WMF нужно заново загрузить список плагинов
(перезапустить WC).

Space — пауза, стрелки влево/вправо — перемотка на 10 секунд, PgUp/PgDn —
соседний файл. При перемотке восстанавливается состояние команд трекера;
последние 60 мс синтезируются для установления огибающих. Фаза генераторов
после перемотки может отличаться от непрерывного воспроизведения.

Размер входного файла — до 32 КиБ, до 255 позиций и 32 паттернов по 64 строки,
до 32 инструментов и орнаментов; один распакованный инструмент/орнамент —
до 4096 тактов. После разбора входной буфер освобождается. Названия и автора
в этом формате нет: окно показывает имя файла.

Сборка: `tools/build_modules.ps1 saa player`. Проверки:
`python -m unittest discover -s tests -p test_saa_source.py`; интеграционные
сценарии SAA также включены в `test_player_host.py` и `test_mp3_plugin_z80.py`.
