# NES / Денди на VDAC4

Ядро — [NESTang](https://github.com/nand2mario/nestang) (commit `5b24a710`) с обвязкой платы VDAC4. Готовые
файлы — [`../SD/CORES/NES.BIN`](../SD/CORES/NES.BIN) (0.10, VERSION `0401000A`) и
[`NES.ELF`](../SD/CORES/NES.ELF) (0.9). Нужен плагин WC VDAC4 Cores 0.13.

## Что здесь

| Папка | Что |
|---|---|
| [`upstream/src`](upstream/src) | процессор 6502, PPU, APU, мапперы и контроллер SDRAM из NESTang |
| [`fpga`](fpga) | обвязка VDAC4: верхний модуль, LINK с ESP, меню на экране, мост к картам для снимков и сохранений, масштаб 4:3/16:9 |
| [`esp`](esp) | слой ESP `NES.ELF`: выбор картриджа с карт Tang и Evo, клавиатура и Kempston, звук на ЦАП ESP, `.sav` и снимки `.sst` |
| [`build.tcl`](build.tcl) | сборка в Gowin EDA |

## Возможности

- Картриджи `.nes` с карты Tang и с карты Evo (F1 — меню выбора, игра на паузе).
- Меню F1 (ядро 0.10, NES.ELF 0.9): папки, затем игры — по имени без учёта регистра; шапка с вкладками
  TANG SD / EVO SD, путь и страница, значки папок, размеры игр с карты Tang, строка состояния с итогом
  папки, ошибкой или ходом загрузки (полоса и процент), подсказки — клавиши голубым. ↑/↓, PgUp/PgDn,
  Home/End; после выхода из папки курсор — на ней. Со старым ядром — то же знаками ASCII.
- Запуск NES из меню ядер плагина (0.7) — сразу меню F1: ядро стоит на паузе, Esc и F1 меню не
  закрывают, пока не выбран `.nes`; F12 — назад в WC. Файл, который не загрузился, оставляет меню
  открытым с текстом ошибки. Enter на `.nes` в панели WC по-прежнему запускает игру сразу.
- Сохранения battery в `.sav` рядом с картриджем на той же карте, снимки всей машины F5/F6 в `.sst`.
- Мапперы NESTang. Снимки поддерживают MMC1, MMC2, MMC3, MMC4, 28, 34, 66, 71.
- Kempston всеми восемью битами: огонь / B Sega → A, A Sega → B, C → Select, START → Start.
- Звук на ЦАП ESP, картинка на HDMI 720p, пропорции 4:3 или 16:9 (F7).
- Размер картинки 100 / 95 / 90 % (ядро 0.9, NES.ELF 0.8) — против вылета за край на старых HDMI-приёмниках.
  По умолчанию AUTO: тот же, что SIZE в TS-Config (слот 0). В меню F1 — F8: AUTO → 100 → 95 → 90 %,
  выбор хранится в `CORES/nes.cfg` (`picture_size`). Картинка сжимается к центру, вокруг — чёрное.
- Звук (NES.ELF 0.8): отсчёт ядра читается без знака, постоянная составляющая убирается фильтром около
  37 Гц, как у Famicom. До 0.8 NES.ELF читал его как знаковый: звук шёл на полную шкалу, а в громких местах
  перескакивал с −32768 на +32767, отсюда щелчки и искажения.

## Сборка

Ядро: Gowin EDA 1.9.11. Рядом с `build.tcl` нужны папки `fpga` и `upstream/src` и файл `background.txt`.
Команда `gw_sh build.tcl`, результат — `impl/pnr/nesVdac4.bin` (это `NES.BIN`). Слой ESP: ESP-IDF 6.0,
`esp/tools/build.ps1`.
