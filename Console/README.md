# Консоль VDAC4 — журнал ESP по сети

`VDAC4Console.exe` — окно для Windows 10/11, которое показывает журнал ESP платы VDAC4 вживую.
Ни Python, ни USB, ни установки не нужно: программа — один файл, .NET Framework 4.8 уже есть в Windows.

## Как снять журнал для разработчика

1. Включите Evo с платой VDAC4. ESP должен быть подключён к Wi-Fi, ПК — в той же сети.
2. Запустите `VDAC4Console.exe`. Если Windows покажет «Windows защитила ваш компьютер» (у программы
   нет цифровой подписи), нажмите «Подробнее», затем «Выполнить в любом случае».
   Плату программа найдёт сама; адрес запоминается до следующего раза (файл `VDAC4Console.ini` рядом
   с программой). Не нашла — введите адрес вручную и нажмите «Подключить»: адрес показывают плагины
   FTP Server и SMB Server в Wild Commander (строка «IP»).
3. Дождитесь зелёной строки «Подключено». В окне — вывод ESP с включения платы (последние 32 КБ)
   и дальше всё новое.
4. Повторите сбой на Evo (например, запустите ядро в плагине Cores).
5. Нажмите «Сохранить в файл…» и пришлите файл.

Кнопка «log» добавляет журнал из флеша ESP: около 250 последних записей, он переживает
перезагрузку. Не нажимайте её во время игры: чтение флеша приостанавливает ESP.

Консоль платы принимает только одного клиента. Пока окно открыто, другие программы подключиться
к ней не могут — закройте окно, когда журнал больше не нужен.

## Как это устроено

- Поиск платы: программа стучится на порт 8268 по адресам сетей своих адаптеров и ждёт строку
  `ZIFI-TANG/1 <версия>` (её шлёт ESP, `tang_update.cpp`). Плате ничего не отправляется.
- Журнал: TCP-порт 23, сетевая консоль ESP (`src/net_console.cpp`). Обрыв (перезагрузка платы,
  пропал Wi-Fi) — программа подключается снова каждые 3 секунды.
- Кнопки ver, mem, top, tang, log только читают. Строка «Команда» отправляет на плату любую
  команду консоли как есть.

## Сборка и проверки

```
powershell -ExecutionPolicy Bypass -File build.ps1 -Test
```

Нужен компилятор C# из Visual Studio 2022 Build Tools. Проверки на ПК (`tests/TestMain.cs`)
гоняют программу против моделей консоли ESP и порта 8268: история с русским текстом, разорванным
на байты, команды, переподключение, «консоль занята», отказ порта, поиск платы, окно с 40 КБ текста,
освобождение консоли при закрытии окна.

# VDAC4 Console — ESP log over the network

`VDAC4Console.exe` shows the ESP log of a VDAC4 board live, on Windows 10/11, without Python or USB.
Start it, wait for the green "Connected" line, repeat the failure on the Evo, press "Save to file…"
and send the file. The program finds the board itself (ESP port 8268) and reads the ESP network
console (port 23). The console takes one client: close the window when you no longer need the log.
