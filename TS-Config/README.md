# Прошивка Evo: TS-Config для VDAC2 с SPI 28 МГц

[`zxevo_fw_vdac2-spi28.bin`](zxevo_fw_vdac2-spi28.bin) — прошивка самой ZX Evolution: конфигурация
TS-Config с Base Conf, сборка для VDAC2 с ключом `ESP32_SPI` (бит 4 порта `#77` выбирает ESP). От
опубликованной TS-Labs [`zxevo_fw_vdac2.bin`](https://github.com/tslabs/zx-evo/tree/master/pentevo/avr/current/default)
она отличается частотой SCK канала SPI: 28 МГц вместо 14 МГц. С этой прошивкой в Evo плата VDAC4
проверялась с первых включений (октябрь 2026). Исходник этой сборки не опубликован.

## Чем отличается

Обмен байтом через порт `#57` идёт вдвое быстрее (8 тактов 28 МГц вместо 16) и успевает закончиться
за цикл чтения порта уже при Z80 на 3,5 МГц. Программы Z80 платы работают с обеими прошивками: перед
данными они получают один или два незначащих байта и это учитывают. Подробно — раздел «Канал SPI» в
[`Docs/VDAC4.md`](../ESP32%20S3%20Zero%20N8R8/Docs/VDAC4.md#канал-spi); что нужно от Evo вообще —
раздел [«Что нужно со стороны Evo и платы»](../ESP32%20S3%20Zero%20N8R8/Docs/VDAC4.md#что-нужно-со-стороны-evo-и-платы).

## Установка

Обычным способом для Evo: файл под именем `ZXEVO_FW.BIN` положить в корень SD-карты и включить Evo,
удерживая SoftReset (на плате Rev.C — контактная пара J6 «soft reset key»). Вернуть штатную прошивку —
тем же способом с файлом TS-Labs.
